Application Dégradé de couleurs 🎨

Créez des dégradés linéaires personnalisés en choisissant deux couleurs.

Utilisez le sélecteur de couleurs pour choisir vos couleurs, ajustez l'orientation du dégradé et copiez le code CSS généré.

Vous pouvez également générer un dégradé aléatoire en cliquant sur le bouton 🎲.

Le code CSS du dégradé sera affiché ci-dessous.

Code CSS généré :

background: linear-gradient(90deg, #f7df1e, #ffa500);
